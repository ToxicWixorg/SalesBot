# 📦 بخش سفارشات من (My Orders)

این بخش برای مدیریت و نمایش سفارشات کاربران طراحی شده است.

## ✨ ویژگی‌ها

### 1️⃣ نمایش لیست سفارشات

- **فیلتر بر اساس وضعیت:**
  - 🔵 سفارشات فعال (Active)
  - ✅ سفارشات تکمیل شده (Completed)
  - 📋 همه سفارشات (All)

- **اطلاعات هر سفارش در لیست:**
  - شماره سفارش (#ID)
  - نام محصول
  - وضعیت با emoji و رنگ مناسب
  - تاریخ ثبت سفارش
  - قیمت نهایی

### 2️⃣ جزئیات سفارش

وقتی کاربر روی یک سفارش کلیک کند، اطلاعات زیر نمایش داده می‌شود:

#### اطلاعات اصلی:

- 🆔 شماره سفارش
- 📦 نام محصول
- 🎨 وضعیت سفارش (با رنگ و emoji)
- 💰 قیمت اولیه
- 🎁 مبلغ تخفیف (در صورت وجود)
- 💳 مبلغ استفاده شده از کیف پول
- ✅ قیمت نهایی
- 📅 تاریخ ثبت سفارش
- ✨ تاریخ تحویل (برای سفارشات تکمیل شده)
- 🗓️ زمان زمان‌بندی شده (برای سفارشات Custom)

#### اطلاعات تحویل (برای سفارشات تکمیل شده):

- 🔐 کد محصول
- 📧 ایمیل
- 🔗 لینک
- 📝 دستورالعمل‌ها

### 3️⃣ عملیات روی سفارش

#### 💬 باز کردن تیکت

- برای همه سفارشات قابل استفاده
- ارتباط مستقیم با پشتیبانی برای مشکلات

#### 🔄 تمدید اشتراک

- فقط برای محصولات قابل تمدید (`isRenewable: true`)
- فقط برای سفارشات با وضعیت:
  - ✅ تکمیل شده (completed)
  - ✨ فعال (active)
  - ⚡ نزدیک به پایان (expiring_soon)

#### 📅 تغییر زمان

- فقط برای سفارشات Custom Order
- فقط برای وضعیت‌های:
  - 📅 منتظر انتخاب زمان (waiting_schedule)
  - 🗓️ زمان‌بندی شده (scheduled)

#### ⚠️ گزارش مشکل

- فقط برای سفارشات:
  - ✅ تکمیل شده (completed)
  - ✨ فعال (active)

## 🔌 نحوه استفاده

### دسترسی از منوی اصلی

کاربر روی دکمه **"📦 سفارشات من"** در منوی اصلی کلیک می‌کند.

### Callback Query

```typescript
.callbackQuery("my_orders", async (context) => {
  // نمایش لیست سفارشات
})
```

### فیلتر سفارشات

```typescript
// سفارشات فعال
.callbackQuery("orders_filter_active", ...)

// سفارشات تکمیل شده
.callbackQuery("orders_filter_completed", ...)

// همه سفارشات
.callbackQuery("orders_filter_all", ...)
```

### نمایش جزئیات

```typescript
.callbackQuery(/^order_(\d+)$/, async (context) => {
  const orderId = parseInt(context.match[1]);
  // نمایش جزئیات سفارش
})
```

## 🔐 امنیت

- **بررسی مالکیت:** قبل از نمایش جزئیات، بررسی می‌شود که سفارش متعلق به کاربر درخواست‌کننده باشد
- **دسترسی محدود:** هر کاربر فقط به سفارشات خودش دسترسی دارد

## 🚀 ویژگی‌های آینده

این بخش برای ویژگی‌های زیر آماده شده است (به زودی فعال می‌شوند):

1. 🎫 **سیستم تیکت:** باز کردن تیکت مستقیم از سفارش
2. 🔄 **تمدید خودکار:** تمدید سریع اشتراک‌ها
3. 📅 **تغییر زمان:** تغییر زمان سفارشات Custom
4. ⚠️ **گزارش مشکل:** ثبت مشکلات و پیگیری

## 📊 مثال‌ها

### مثال 1: دریافت سفارشات فعال کاربر

```typescript
const activeOrders = await OrderRepository.findByUserId(userId);
const filtered = activeOrders.filter((o) =>
  ["paid", "in_progress", "active"].includes(o.status),
);
```

### مثال 2: نمایش اطلاعات تحویل

```typescript
if (order.delivery && order.status === "completed") {
  const delivery = order.delivery as any;

  if (delivery.code) {
    message += `🔐 کد: \`${delivery.code}\`\n`;
  }

  if (delivery.link) {
    message += `🔗 لینک: ${delivery.link}\n`;
  }
}
```

## 🎯 نکات مهم

1. **محدودیت نمایش:** در هر صفحه حداکثر 10 سفارش نمایش داده می‌شود
2. **مرتب‌سازی:** سفارشات بر اساس تاریخ ثبت (جدیدترین اول) مرتب می‌شوند
3. **فرمت قیمت:** قیمت‌ها با فرمت فارسی نمایش داده می‌شوند (مثلاً: 1,250,000)
4. **فرمت تاریخ:** تاریخ‌ها به صورت فارسی نمایش داده می‌شوند
