- اطلاعات حساب خود را مشاهده کنند
- زبان را تغییر دهند
- نوتیفیکیشن‌ها را مدیریت کنند

## 🎨 ویژگی‌ها

### 1️⃣ اطلاعات حساب کاربری

**مسیر:** `تنظیمات → اطلاعات حساب`

نمایش:

- 🆔 شناسه کاربری
- 👤 نام کاربری
- 📝 نام و نام خانوادگی
- 📅 تاریخ عضویت
- 📊 آمار:
  - تعداد سفارشات
  - مجموع خرید
  - تعداد دعوت‌ها

### 2️⃣ تغییر زبان

**مسیر:** `تنظیمات → تغییر زبان`

زبان‌های پشتیبانی شده:

- 🇮🇷 فارسی
- 🇬🇧 English
- 🇷🇺 Русский

### 3️⃣ تنظیمات اعلان‌ها

**مسیر:** `تنظیمات → تنظیمات اعلان‌ها`

کاربر می‌تواند هر کدام از این نوتیفیکیشن‌ها را فعال/غیرفعال کند:

| نوع اعلان  | توضیح                      | وضعیت پیش‌فرض |
| ---------- | -------------------------- | ------------- |
| 🛒 سفارشات | اطلاع از تغییر وضعیت سفارش | ✅ فعال       |
| 💰 کیف پول | اطلاع از تراکنش‌های مالی   | ✅ فعال       |
| 🎁 تخفیفات | اطلاع از پیشنهادات ویژه    | ✅ فعال       |
| 👥 دعوت‌ها | اطلاع از دعوت دوستان       | ✅ فعال       |
| 📦 موجودی  | اطلاع از موجود شدن محصولات | ✅ فعال       |

**چگونگی کار:**

- کلیک روی هر دکمه، وضعیت آن را تغییر می‌دهد
- تغییرات بلافاصله در دیتابیس ذخیره می‌شوند
- آیکون ✅/❌ وضعیت فعلی را نشان می‌دهد

### 4️⃣ حریم خصوصی

**مسیر:** `تنظیمات → حریم خصوصی`

امکانات:

#### 📤 دریافت اطلاعات من

- تمام اطلاعات کاربر را در یک فایل JSON خروجی می‌گیرد
- شامل: اطلاعات حساب، تراکنش‌ها، سفارشات
- مطابق با GDPR

#### 🗑️ پاک کردن تاریخچه

- پاک کردن تاریخچه تراکنش‌ها
- نیاز به تأیید دارد
- غیرقابل بازگشت

#### ❌ حذف حساب کاربری

- حذف دائمی حساب کاربری
- پاک کردن تمام اطلاعات
- نیاز به تأیید دوباره دارد
- ⚠️ غیرقابل بازگشت

### 5️⃣ درباره ما

**مسیر:** `تنظیمات → درباره ما`

نمایش:

- اطلاعات ربات
- راه‌های ارتباطی
- نسخه نرم‌افزار
- لینک‌های پشتیبانی

## 🔧 استفاده

### برای کاربران

1. **دسترسی به تنظیمات:**

   ```
   منوی اصلی → ⚙️ تنظیمات
   ```

2. **تغییر زبان:**

   ```
   تنظیمات → 🌐 تغییر زبان → انتخاب زبان
   ```

3. **غیرفعال کردن نوتیفیکیشن:**

   ```
   تنظیمات → 🔔 اعلان‌ها → کلیک روی نوع مورد نظر
   ```

4. **دریافت اطلاعات شخصی:**
   ```
   تنظیمات → 🔒 حریم خصوصی → 📤 دریافت اطلاعات
   ```

## 💻 توسعه

### فایل‌های مرتبط

```
bot/src/
├── handlers/
│   └── settings.ts           # Handler اصلی تنظیمات
├── shared/
│   ├── keyboards/
│   │   └── settings.ts       # کیبوردهای تنظیمات
│   └── locales/
│       ├── fa.ts             # متن‌های فارسی
│       ├── en.ts             # متن‌های انگلیسی
│       └── ru.ts             # متن‌های روسی
└── db/
    └── schema.ts             # Schema دیتابیس
```

### Schema دیتابیس

فیلدهای اضافه شده به جدول `users`:

```typescript
{
  notifyOrders: boolean; // اعلان سفارشات
  notifyWallet: boolean; // اعلان کیف پول
  notifyPromotions: boolean; // اعلان تخفیفات
  notifyReferrals: boolean; // اعلان دعوت‌ها
  notifyStock: boolean; // اعلان موجودی
}
```

### Callback Query Pattern

```typescript
// Pattern های استفاده شده:
settings                         // منوی اصلی
settings:account_info           // اطلاعات حساب
settings:notifications          // تنظیمات نوتیفیکیشن
settings:toggle:{type}          // تغییر وضعیت نوتیف
settings:privacy                // حریم خصوصی
settings:privacy:export         // دریافت داده‌ها
settings:privacy:clear_history  // پاک کردن تاریخچه
settings:privacy:delete_account // حذف حساب
settings:confirm:{action}       // تأیید عملیات
settings:about                  // درباره ما
```

### اضافه کردن نوتیفیکیشن جدید

1. به `schema.ts` فیلد جدید اضافه کنید:

```typescript
notifyNewFeature: boolean("notify_new_feature").default(true);
```

2. به `notificationTypes` در `settings.ts` اضافه کنید:

```typescript
const notificationTypes = [
  "orders",
  "wallet",
  "promotions",
  "referrals",
  "stock",
  "newFeature", // جدید
] as const;
```

3. به `fieldMap` اضافه کنید:

```typescript
const fieldMap = {
  // ...
  newFeature: "notifyNewFeature",
};
```

4. متن‌های لازم را به locales اضافه کنید:

```typescript
btnToggleNewFeatureNotifications: (enabled: boolean) =>
  `${enabled ? "✅" : "❌"} اعلان ویژگی جدید`;
```

5. Migration ایجاد کنید:

```sql
ALTER TABLE "users"
ADD COLUMN "notify_new_feature" boolean DEFAULT true;
```

### Testing

```typescript
// تست تغییر وضعیت نوتیفیکیشن
await context.callbackQuery("settings:toggle:orders");

// تست دریافت اطلاعات
await context.callbackQuery("settings:privacy:export");

// تست حذف تاریخچه
await context.callbackQuery("settings:privacy:clear_history");
await context.callbackQuery("settings:confirm:clear_history");
```
